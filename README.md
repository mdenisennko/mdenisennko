### 🚕 Taxi Pricing Analysis
**Python · pandas · statsmodels · Statistics**

Исследование факторов, связанных со стоимостью поездки на данных **7 131 наблюдения**.

Что сделала:
- очистка и подготовка данных;
- EDA;
- визуализация;
- кодирование категориальных признаков;
- OLS-регрессия;
- проверка статистических гипотез;
- сравнение моделей.

**Результат:** итоговая модель достигла **R² = 0,95**; ключевыми предикторами стоимости оказались расстояние и уровень спроса.
