### 🚕 Анализ ценообразования на рынке такси

Провела EDA 7 131 поездки и построила OLS-регрессию для анализа факторов, связанных со стоимостью поездки.

**Стек:** Python, pandas, statsmodels, Matplotlib, Seaborn  

Исследовала факторы, связанные со стоимостью поездок на основе данных о 7 131 поездке.

Провела EDA, подготовила данные и построила OLS-регрессию. Исследовала влияние расстояния, спроса, погоды, времени суток и других факторов на стоимость поездки.

Итоговая модель достигла **R² = 0,95**.

**Стек:** Python, pandas, NumPy, statsmodels, Matplotlib, Seaborn

[Перейти к проекту →](https://github.com/mdenisennko/taxi-pricing-analysis)
